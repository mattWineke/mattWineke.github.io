# Matthew Wineke — Portfolio

Personal portfolio website for Matthew Wineke, a Computer Science student at the University of Maryland, Baltimore County (UMBC) focused on machine learning, AI, software engineering, and systems programming.

## Live site

https://mattWineke.github.io

## Highlights

- Retriever Care demand-forecasting project
- Linux operating-systems projects
- Data structures and algorithms work
- Education, experience, technical skills, and awards
- Responsive dark/light design
- Printable public résumé page

## Stack

Plain HTML, CSS, and JavaScript. No build step or runtime dependencies are required.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any local static-file server.

## Deployment

This repository is designed for GitHub Pages. Because the repository is named `mattWineke.github.io`, the site can be published directly from the `main` branch root.
